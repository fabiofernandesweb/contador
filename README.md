# 🧮 Projeto Contador

Um projeto simples de **Contador** desenvolvido com **HTML, CSS e JavaScript puro**, com foco em manipulação do DOM e lógica básica de programação.

---

## 🚀 Funcionalidades

- ➕ Incrementar valor
- ➖ Decrementar valor
- 🔄 Resetar contador
- 🎯 Atualização dinâmica na tela

---

## 🖥️ Preview
https://fabiofernandesweb.github.io/contador/

O contador inicia em **0** e permite ao usuário interagir com três botões:

- **Incrementar** → aumenta o valor
- **Decrementar** → diminui o valor
- **Resetar** → volta para zero

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)
